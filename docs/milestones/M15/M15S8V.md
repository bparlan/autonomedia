## Edge Cases

### Empty Database
- Approved items list empty → batch-generate no-op, return empty table

### Invalid Item ID
- Approve non-existent item → 404 error in row (not full page error)

### Status Transitions
- Item changing during polling → show latest status
- Concurrent approve/reject → last write wins

### Platform States
- All platforms healthy → show green status
- All platforms unhealthy → show red status
- Mixed states → show individual platform status

---

## Failure Scenarios

### HTMX Redirect Error
- Route returns redirect instead of HTML fragment
- Row element replaced with full page content

### Status Polling Error
- Database error during polling → 500 error in fragment
- Should show error state, not break page

### Platform Auth Error
- Re-auth fails → show error message
- Platform connection timeout → show timeout status
