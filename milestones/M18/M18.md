## Milestone Contract

This milestone evolves the infrastructure health monitoring into an integrated, verifiable health dashboard within the Autonomedia system.

- **Goal**: Build an integrated health dashboard page within the Autonomedia web interface, providing real-time visibility into infrastructure status (`src/`, `scripts/`, `runtime/`, `tests/`) and resolving findings from the M18 audit.
- **Motivation**: Existing health monitoring is reactive and CLI-based. Moving to a persistent, verifiable dashboard makes infrastructure health visible, actionable, and monitorable via AEF/SDD verification protocols.
- **Externally Observable Outcome**: A new `/health` dashboard page accessible via the web interface, showing the status of database, runtime directories, test suite, and source integrity.
- **Key Constraints**: Dashboard must use established project infrastructure (Autonomedia web stack); status must be verifiable via automated tests; secure access (if applicable); no hardcoded configurations.
- **Important Invariants**: Dashboard status must consistently reflect backend healthcheck results.
- **Critical Security/Safety Boundaries**: Dashboard must not expose sensitive infrastructure details or credentials.
- **Scope Boundary**: Development of the health dashboard page, integration of existing `healthcheck` utility, and verification/tests for the dashboard itself.

## Success Criteria

- [ ] New `/health` dashboard page is accessible and displays real-time system status.
- [ ] Backend `healthcheck.py` results are exposed via an authenticated endpoint used by the dashboard.
- [ ] Dashboard includes status indicators for Database, Runtime, Tests, and Source integrity.
- [ ] Verified via automated tests (browser/API checks) ensuring dashboard updates correctly when status changes.
- [ ] All legacy `scripts/checks/` retired (as per M18 audit).
- [ ] `runtime/sessions` directory issue resolved or initialization logic updated.

## Verification Strategy

- FR-4: DASHBOARD_ACCESSIBILITY - Web dashboard returns 200 OK and valid health status JSON/UI.
- FR-5: DASHBOARD_VERIFICATION - Automated test verifies dashboard status reflects backend check results.

## Risks

- Integrating infrastructure health into web UI creates dependency between infrastructure state and web server availability.
- Web dashboard security (access control to infrastructure status).

## Notes

The dashboard is the primary verification tool for the health of the Autonomedia AEF infrastructure.
