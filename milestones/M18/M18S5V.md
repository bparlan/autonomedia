## Environment Setup Requirements

#### Prerequisites

1. **Node Dependencies:** None required for M18S5

2. **Python Dependencies:**
   - FastAPI (`pip install fastapi`)
   - Uvicorn (`pip install uvicorn`)
   - Playwright (`pip install playwright`)
   - Requests (`pip install requests`)

3. **Browser Installation:**
   ```bash
   playwright install chromium
   ```

4. **Environment Variables:**
   ```bash
   BASE_URL="http://localhost:8000"
   ```

5. **Test Environment:**
   - Autonomedia web server running on `http://localhost:8000`
   - Playwright browsers installed and available
   - All test dependencies installed

#### Environment Validation Commands

1. **Check Server Status:**
   ```bash
   curl -s -o /dev/null -w "%{http_code}" http://localhost:8000/api/health
   ```

2. **Check Playwright Installation:**
   ```bash
   python3 -m playwright --version
   ```

3. **Validate Environment Variables:**
   ```bash
   echo $BASE_URL
   ```
