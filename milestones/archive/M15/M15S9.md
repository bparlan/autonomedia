## Objective

Complete remaining HTMX flow fixes for reset_failure, remove_from_queue, and status_fragment handlers. Add loading states to buttons for user feedback.

---

## Functional Requirements

### FR9.1: Fix Reset Failure HTMX Flow

**FR9.1.1**: The `/reset-failure/{item_id}` route handler shall return HTML fragment.
- Return rendered `content_row.html` partial with updated item
- Use `hx-swap="outerHTML"` to replace entire `<tr>` element
- Remove redirect pattern

### FR9.2: Fix Remove From Queue HTMX Flow

**FR9.2.1**: The `/remove-from-queue/{item_id}` route handler shall return HTML fragment.
- Return rendered `content_row.html` partial with updated item
- Use `hx-swap="outerHTML"` to replace entire `<tr>` element

### FR9.3: Fix Status Fragment Element Return

**FR9.3.1**: The `/status-fragment/{item_id}` route handler shall return proper `<td>` element.
- Return only status cell HTML
- Match the exact `<td>` structure from content_row.html
- Include correct status badge based on actual item status

### FR9.4: Add Loading States to Buttons

**FR9.4.1**: All HTMX action buttons shall show loading state.
- Add `hx-indicator` attribute to show spinner/loading
- Disable button during request
- Restore button after response
