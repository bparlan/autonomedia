## Edge Cases

### Authentication Edge Cases

- Expired token: Should trigger reauthentication automatically
- Invalid token: Should return clear error message
- Network failure: Should retry with exponential backoff
- Token storage failure: Should log error but not crash

### Content Adaptation Edge Cases

- Content exactly at limit: Should be accepted
- Content slightly over limit: Should be truncated with ellipsis
- No tags provided: Should use empty tag list
- Multiple links: Should preserve all links
- Special characters in content: Should be preserved

### Reauthentication Edge Cases

- Browser profile not found: Should handle gracefully
- OAuth flow interrupted: Should cancel reauthentication
- Token refresh fails: Should show error and log
- Multiple concurrent reauth: Should serialize or show error

### Validation Edge Cases

- Empty content: Should reject
- Content with only whitespace: Should reject
- Special characters in tags: Should handle gracefully
- International characters: Should handle correctly
