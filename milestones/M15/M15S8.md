## Objective

Fix HTMX flow issues preventing proper in-place updates and add platform management features for the web dashboard.

---

## Functional Requirements

### FR8.1: Approve Button HTMX Flow

**FR8.1.1**: The `/approve-idea/{item_id}` route handler shall return HTML fragment for HTMX replacement.
- Return rendered `content_row.html` partial with updated item
- Use `hx-swap="outerHTML"` to replace entire `<tr>` element
- Remove redirect pattern (not compatible with HTMX row targeting)

**FR8.1.2**: The `content_row.html` template shall maintain proper HTMX attributes.
- `hx-target="#row-{{ item.id }}"` targets the correct row
- `hx-swap="outerHTML"` replaces entire row element
- Form validation errors return inline error messages

### FR8.2: Status Fragment Real-Time Updates

**FR8.2.1**: The `/status-fragment/{item_id}` route handler shall return actual item status.
- Query the database for current item status
- Return mapped status badge based on actual `status` and `verification_status` fields
- Remove hardcoded "Generating" text

**FR8.2.2**: The status cell shall only poll when actively processing.
- Poll only for `approved` or `rewriting` status
- Stop polling after status changes to final state
- Display correct status badge (not static "Generating")

### FR8.3: Batch Generate HTMX Flow

**FR8.3.1**: The `/batch-generate` route handler shall update items in-place.
- Return updated content using `content.html` template items
- Use appropriate HTMX target (table container, not body)
- Stay on `/rewrites` page after action

**FR8.3.2**: The `rewrites.html` template shall use correct HTMX target.
- Change `hx-target="body"` to `hx-target` appropriate table container
- Update status badges without full page reload

### FR8.4: Platform Status Re-authentication

**FR8.4.1**: The `/platforms` page shall include platform management controls.
- Display connection status (connected/disconnected)
- Show "Re-authenticate" button for connected platforms
- Show "Connect" button for disconnected platforms

**FR8.4.2**: The `/platforms` page shall support adding new platforms.
- Form to add platform (select from available: linkedin, x, mastodon)
- Display platform-specific credential status

---

## Non-Functional Requirements

### NFR8.1: HTMX Compatibility
- All HTMX requests shall receive HTML fragments, not redirects
- Target elements shall be properly scoped
- No full page loads within partial targets

### NFR8.2: Performance
- Status polling shall use efficient queries (indexed by primary key)
- Avoid unnecessary database calls during polling
