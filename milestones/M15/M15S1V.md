## Edge Cases

### Empty Content
- Empty string as content: Should return validation error
- Empty title: Should use first 200 characters (or all if shorter)
- Empty tags: Should return empty tag list

### Maximum Character Limits
- Title exactly 300 characters: Should include all characters, no truncation
- Title 301 characters: Should truncate to 300
- Summary exactly 3000 characters: Should include all characters
- Summary 3001 characters: Should truncate to 3000

### Tag Boundary Cases
- 6 tags: Should only use first 5 tags
- Tag with 26 characters: Should truncate to 25 characters
- Tag with special characters: Should preserve as-is

### Hashtag Boundary Cases
- 4 hashtags: All preserved
- 5 hashtags: All preserved
- 6 hashtags: Only first 3 preserved
- Hashtag with numbers: "#AI2024" should become "#AI2024" (numbers at end)

### Anti-Detection Edge Cases
- Viewport size: Should use randomized viewport sizes (e.g., 1920x1080, 1366x768, 1440x900)
- Delays: Should use randomized delays between 5-10 seconds, not fixed 5-second intervals
- Browser profile: Should use anti-detection profile (Headless mode disabled)

### Authentication Edge Cases
- Missing credentials: Should return clear error message
- Token without required permissions: Should return 403 error
- Token with invalid scope: Should return 403 error

### Content Adaptation Edge Cases
- Content with no paragraph breaks: Should work normally
- Content with many paragraph breaks: Should preserve paragraph structure
- Content with unicode: Should handle unicode characters correctly
- Content with special characters: Should handle correctly

### Concurrent Operations
- Multiple platform posts simultaneously: Should handle concurrently without conflicts
- Multiple batches posted simultaneously: Should handle without rate limit issues
