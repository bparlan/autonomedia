## Public API Changes

### New Functions
- `get_platform_constraints(platform_name: str)` - Returns character limits, field requirements, and formatting rules for a platform
- `adapt_content_for_platform(content: str, platform: str)` - Truncates and adapts content to meet platform-specific constraints

### New Methods
- `PlatformHandler.get_rate_limit_status()` - Abstract method returning platform-specific rate limit information
- `XHandler.get_rate_limit_status()` - Returns X/Twitter rate limits (300 requests per 15 min window)
- `LinkedInHandler.get_rate_limit_status()` - Returns LinkedIn API rate limits
- `MastodonHandler.get_rate_limit_status()` - Returns Mastodon rate limits
- `ReauthManager.check_rate_limits()` - Checks rate limit status for all platforms

### New Endpoints
- `GET /health` - Health check endpoint returning status/timestamp
- `GET /platform-status` - Returns platform availability and rate limit status
- `POST /add` - Creates content from form input
- `POST /approve-idea/{item_id}` - Approves idea and transitions to rewriting
- `POST /batch-generate` - Triggers AI rewriting for approved items
- `POST /review/{id}/approve` - Final approval with status transition validation
- `GET /edit-content-row/{item_id}` - Edit form for content
- `POST /save-content-row/{item_id}` - Saves content edits
- `DELETE /delete-item/{item_id}` - Removes item from database
- `POST /reset-failure/{item_id}` - Resets failed status
- `POST /remove-from-queue/{item_id}` - Removes from posting queue
- `GET /status-fragment/{item_id}` - Returns status HTML for HTMX updates
