# Verification Protocol: M20S2 - Integration Binding Validation Across All Layers

## Objective

Establish the deterministic verification contract for `SPEC-M20S2`. This verification protocol translates functional and non-functional requirements from `SPEC-M20S2` into testable verification items with explicit methods, preconditions, expected evidence, failure conditions, initial failure expectations, and post-implementation success expectations.

## Verification Items Inventory

### VER-M20S2-001
* **Source Requirement ID**: `FR-INTEGRITY_CORE_AI_BINDING`
* **Verification Method**: `SCRIPT_EXECUTION`
* **Target**: `scripts/checks/integrity_core_ai.py`
* **Preconditions**: Repository root contains project files; Core Infrastructure (`src/autonomedia/core/`) and AI Engine (`src/autonomedia/ai/rewriting/`) modules present.
* **Input / Fixture**: Execution command: `uv run python scripts/checks/integrity_core_ai.py --validate --output storage/data/integration_core_ai_binding.json` with environment variable `REPO_ROOT=.`
* **Expected Evidence**: Process exits with code `0`; `storage/data/integration_core_ai_binding.json` is created; JSON contains valid schema with `validated_bindings` array, `violations` array, and `total_bindings` number. Core Infrastructure ↔ AI Engine integration boundaries respected.
* **Failure Condition**: Process exits with non-zero status; `integration_core_ai_binding.json` is missing, malformed, or contains cross-layer violations.
* **Initial Failure Expectation**: Exit code `1` or `127` (Script Not Found prior to implementation).
* **Post-Implementation Success Expectation**: Exit code `0`, JSON report generated with 100% valid core-AI bindings.

### VER-M20S2-005
* **Source Requirement ID**: `FR-INTEGRITY_RUNTIME_DETERMINISM`
* **Verification Method**: `SCRIPT_EXECUTION`
* **Target**: `scripts/checks/integrity_runtime_determinism.py`
* **Preconditions**: Repository root contains project files; Integration validation scripts implemented and can be executed multiple times.
* **Input / Fixture**: Execution commands: 
  - First run: `uv run python scripts/checks/integrity_runtime_determinism.py --validate --output storage/data/integration_binding_matrix_1.json`
  - Second run: `uv run python scripts/checks/integrity_runtime_determinism.py --validate --output storage/data/integration_binding_matrix_2.json`
  - Comparison: `uv run python scripts/checks/integrity_runtime_determinism.py --validate --compare storage/data/integration_binding_matrix_1.json storage/data/integration_binding_matrix_2.json`
* **Expected Evidence**: First run exits with code `0`; second run exits with code `0`; comparison exits with code `0`; SHA-256 checksums of `integration_binding_matrix_1.json` and `integration_binding_matrix_2.json` match 100%; `storage/data/integration_binding_matrix_1.json` and `storage/data/integration_binding_matrix_2.json` generated with valid schema containing `validated_bindings` and `violations` arrays; `storage/data/integration_determinism_report.json` generated with `checksum_match: true` and `determinism_compliant: true`.
* **Failure Condition**: SHA-256 checksums differ between runs; comparison exits with non-zero status; determinism report shows `checksum_match: false` or `determinism_compliant: false`.
* **Initial Failure Expectation**: Script execution failure prior to implementation (exit code `1` or `127`).
* **Post-Implementation Success Expectation**: Identical checksums and `determinism_compliant: true`.
