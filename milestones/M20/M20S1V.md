#### Objective

Establish the deterministic verification contract for `SPEC-M20S1`. This verification protocol translates functional and non-functional requirements from `SPEC-M20S1` into testable verification items with explicit methods, preconditions, expected evidence, failure conditions, initial failure expectations, and post-implementation success expectations.

---

#### Verification Items Inventory

##### `VER-M20S1-001`
*   **Source Requirement ID**: `FR-DIR_AUDIT_SCRIPT`
*   **Verification Method**: `SCRIPT_EXECUTION`
*   **Target**: `scripts/checks/check_directory_structure.py`
*   **Preconditions**: Repository root contains project files; `storage/data/` directory exists or is creatable.
*   **Input / Fixture**: Execution command: `uv run python scripts/checks/check_directory_structure.py` with environment variable `REPO_ROOT=.`
*   **Expected Evidence**: Process exits with code `0`; `storage/data/compliance_report.json` is created; JSON contains valid schema with `compliance_score` equal to `100.0`, `violations` array, and ISO-8601 `timestamp`.
*   **Failure Condition**: Process exits with non-zero status; `compliance_report.json` is missing, malformed, or has `compliance_score < 100.0`.
*   **Initial Failure Expectation**: Exit code `1` or `127` (Script Not Found / Command Not Found prior to implementation).
*   **Post-Implementation Success Expectation**: Exit code `0` and compliance score `100.0`.

##### `VER-M20S1-002`
*   **Source Requirement ID**: `FR-LEGACY_PURGE`
*   **Verification Method**: `SCRIPT_EXECUTION`
*   **Target**: `scripts/checks/verify_legacy_cleanup.py`
*   **Preconditions**: Legacy directories (`tests/M18/`, `tests/M16/`) present in workspace; audit logger initialized.
*   **Input / Fixture**: Execution commands: `uv run python scripts/checks/verify_legacy_cleanup.py --dry-run` and `uv run python scripts/checks/verify_legacy_cleanup.py --execute`
*   **Expected Evidence**: Dry-run exits with code `0` and outputs preview report; execute mode exits with code `0`, removes legacy directories safely without breaking references, and writes `storage/data/purge_report.json` and audit log entries.
*   **Failure Condition**: Process exits with non-zero status; referenced files are deleted; purge report missing or malformed.
*   **Initial Failure Expectation**: Exit code `1` or `127` (Script Not Found prior to implementation).
*   **Post-Implementation Success Expectation**: Exit code `0`, legacy directories purged, and purge report verified.

##### `VER-M20S1-003`
*   **Source Requirement ID**: `FR-COMPLIANCE_CHECK`
*   **Verification Method**: `SCRIPT_EXECUTION`
*   **Target**: `scripts/checks/validate_3layer_pattern.py`
*   **Preconditions**: Python source files present across `src/`, `tests/`, and `storage/`.
*   **Input / Fixture**: Execution command: `uv run python scripts/checks/validate_3layer_pattern.py`

*   **Post-Implementation Success Expectation**: Exit code `0` and 100% valid integration bindings.

Initial failure states are explicitly defined for pre-implementation Red state validation.
