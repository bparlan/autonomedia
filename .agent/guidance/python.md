# Agent Guidance: Python Stack Conventions

> Generated by `bootstrap-project`. Applies to `autonomedia-snapshot`.

## Environment

- Package manager: `uv` only. Never invoke bare `python`, `pip`, `pytest`, or `uvicorn`.
  Always use `uv run <cmd>`.
- Python version: 3.12 (see `pyproject.toml` `target-version`).
- `.python-version` is managed by `uv`; do not modify without checking impact on `uv sync`.

## Linting & Formatting

- Formatter: `ruff format` (quote-style: double, indent: space).
- Linter: `ruff check` with selects `E`, `F`, `ASYNC`, `I`, `UP`, `T20`.
- No `console.log` / `print` in committed code — use `structlog` (structured JSON logs).
- Run `just fix` before committing to auto-fix lint and format.

## Type Checking

- `mypy` with `strict = true`.
- `disallow_untyped_defs = true`, `check_untyped_defs = true`.
- Tests (`tests.*`) have `ignore_missing_imports = true` override.
- Run `just lint` (which includes `mypy`) before claiming completion.

## Module Boundaries

- Application code lives in `src/autonomedia/`.
- Database schema in `src/autonomedia/database/schema.py`.
- Platform adapters in `src/autonomedia/platforms/{platform}/`.
- AI rewrite providers in `src/autonomedia/ai/rewriting/`.
- UI routes in `src/autonomedia/web/router.py` and `src/autonomedia/api/router.py`.
- Scripts in `scripts/`, with health checks in `scripts/checks/` and DB migrations in `scripts/db/`.

## Testing Conventions

- Test files organized as `tests/unit/`, `tests/integration/`, `tests/e2e/`.
- Milestone-specific tests under `tests/M{X}/`.
- Use `tests/conftest.py` for shared fixtures (e.g., `db_pool` fixture).
- Async tests use `pytest-asyncio`.

## Pre-commit

- Pre-commit runs on every commit: sensitive-file check + ruff + mypy.
- Fix issues before staging — pre-commit will block commits that fail.

## AI Policy Guardrails

- **Permitted:** rewrite generation, shortening, tone adaptation, CTA optimization, analytics summarization.
- **Prohibited:** runtime orchestration, queue management, browser state control, recursive planning.
